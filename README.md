# 🛍️ FNP Sales Analysis Dashboard

![FNP Sales Analysis Dashboard](Fnp%20Sales%20Analysis.png)

## 📊 Project Overview
This project presents a **Sales Analysis Dashboard** created in **Microsoft Excel** for **Ferns N Petals (FNP)**.  
The dashboard provides a comprehensive view of sales performance across multiple dimensions — including **occasions, categories, products, months, and cities**.  
It is designed to help stakeholders track key business metrics, identify sales trends, and make data-driven decisions.

---

## 🎯 Objectives
- Analyze **total revenue**, **orders**, and **customer spending**.
- Understand **sales patterns** by **occasion**, **category**, and **time of order**.
- Identify **top-performing products** and **high-demand cities**.
- Monitor **average order-to-delivery time** for operational efficiency.

---

## 📈 Key Insights
| Metric | Description |
|--------|--------------|
| **Total Orders** | 1,000 orders analyzed |
| **Total Revenue** | ₹ 35,20,984 |
| **Average Customer Spending** | ₹ 3,520.98 |
| **Average Delivery Time** | 5.53 days |

### 🔹 Revenue Breakdown
- **By Occasion:** Highest revenue from *Anniversary* and *Raksha Bandhan* sales.  
- **By Category:** *Flowers* and *Soft Toys* lead the sales categories.  
- **By Month:** *February* and *August* show peak sales, likely due to *Valentine’s Day* and *Raksha Bandhan*.

### 🔹 Top Performers
- **Top 5 Products:** Magnum Set, Quia Gift, Dolores Gift, Harum Pack, Deserunt Box.  
- **Top 10 Cities by Orders:** Surat, Dhanbad, Kaulal, Haridwar, Bhilwara, Durg, Guna, North Dumdum, Bilaspur, Bhopara.

## 🚀 How to Use
1. Download the Excel file from the repository.  
2. Open it in **Microsoft Excel (2016 or later)**.  
3. Use the slicers to filter data by **date**, **gender**, or **occasion**.  
4. Analyze the charts and KPIs to gain business insights.
